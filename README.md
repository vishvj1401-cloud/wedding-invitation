# Anjana & Yadukrishna Wedding Invitation

A single React invitation template with three separate invite routes:

- `marriage.html` - Thalikettu ceremony details and location
- `reception.html` - Reception details and location
- `full.html` - Wedding and reception details together

## Preview Locally

```bash
node server.mjs
```

Then open:

- `http://localhost:4173/marriage`
- `http://localhost:4173/reception`
- `http://localhost:4173/full`

The app uses React, Tailwind CSS, Google Fonts, and `lucide-react` from browser CDNs.

## GitHub Pages URLs

After uploading these files to the `vishvj1401-cloud/wedding-invitation` repository and enabling GitHub Pages from the `main` branch root, the invite URLs should be:

- Marriage: `https://vishvj1401-cloud.github.io/wedding-invitation/marriage.html`
- Reception: `https://vishvj1401-cloud.github.io/wedding-invitation/reception.html`
- Full invite: `https://vishvj1401-cloud.github.io/wedding-invitation/full.html`
